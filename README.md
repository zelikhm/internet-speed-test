# Internet Speed Test

Простой консольный инструмент на Python для измерения скорости скачивания файла по HTTP/HTTPS.

## Требования

- Python 3.10+

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py "https://example.com/large-file.jpg"
```

Замените URL на адрес доступного файла.

## Как работает

- Выполняет 10 последовательных GET-запросов.
- Полностью скачивает тело каждого ответа.
- Измеряет время каждого запроса.
- Рассчитывает среднее время, суммарный объём данных и скорость скачивания.

## Единицы измерения

- Время — секунды (с).
- Объём — мебибайты (МиБ), 1 МиБ = 1 048 576 байт.
- Скорость — мегабиты в секунду (Мбит/с), 1 Мбит/с = 1 000 000 бит/с.

Формула расчёта скорости:

```text
speed = total_bytes * 8 / total_seconds / 1_000_000
```

Время включает получение HTTP-ответа и полное чтение его тела.

Результат отражает скорость HTTP-скачивания с конкретного сервера, а не гарантированную максимальную пропускную способность интернет-канала.

## Ограничения

Для корректного замера рекомендуется использовать большой файл, доступный без авторизации.

Серверное кеширование, ограничения скорости сервера и сетевые условия могут влиять на результат.
